# Frozen docs: LibreYOLO 1.5.0

This directory is a snapshot of `content/docs/` taken from the website's `main`
branch at commit `19c1ca6`, the last state of the docs tree for LibreYOLO 1.5.0.
Its registry, sidebar manifest and upstream metadata are frozen alongside it in
`src/data/docs/archive/v1.5.0/`.

It is served at `/docs/v1.5.0/...` (and the locale-prefixed equivalents) so
readers pinned to 1.5.0 keep the exact docs for that release. Every page
canonicalises to its counterpart in the current `/docs` tree.

**Frozen. Never edit these files.** Fixes go into the current tree under
`content/docs/`. The only permitted change is replacing the whole snapshot by
copying again from `main` at release time.

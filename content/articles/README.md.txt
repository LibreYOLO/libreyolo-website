HOW TO PUBLISH AN ARTICLE

1. Create a new .md file in this folder (content/articles/).
   The filename becomes the URL: my-article.md -> libreyolo.com/articles/my-article

2. Start the file with this frontmatter block:

---
title: Your Article Title
description: One sentence summary (shown in Google results and the article list).
date: 2026-06-15
author: Your Name
tags: [LibreYOLO, tutorial]
---

3. Write the article below it in normal Markdown (headings, code blocks, images, tables all work).

4. Commit and deploy. The article appears automatically on /articles and in the sitemap.

Note: this file ends in .txt so it is not published as an article itself.

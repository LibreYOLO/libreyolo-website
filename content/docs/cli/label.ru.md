## Синтаксис

```bash
libreyolo label [data=<dataset.yaml|folder>] [key=value ...]
```

Аргументы задаются парами `key=value`, POSIX-форма тоже работает, поэтому
`port=9200` и `--port 9200` — один и тот же аргумент.

## Аргументы

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `data` | | YAML датасета или папка, которую нужно открыть сразу. Без него запуск начинается с главной страницы проекта |
| `host` | `127.0.0.1` | Хост или интерфейс для привязки |
| `port` | `8000` | Порт для привязки. Если занят, берётся следующий свободный |
| `device` | `auto` | Устройство для AI-разметки: `0`, `cpu`, `mps`, `auto` |
| `no_assist` | `false` | Отключить AI-разметку и оставить только ручную |
| `no_browser` | `false` | Не открывать браузер автоматически |
| `share` | `false` | Привязка к `0.0.0.0`, чтобы коллеги в вашей сети могли подключиться |
| `json` | `false` | Вывод JSON в stdout |
| `quiet` | `false` | Подавить stderr |
| `verbose` | `false` | Подробный вывод в stderr |

## Примечания

### Что записывается

Рамки сохраняются в файлы `labels/*.txt` в родном формате LibreYOLO — том самом,
который читает `libreyolo train`, поэтому конвертировать потом ничего не нужно.
Эта версия работает только с ограничивающими рамками. Правки сохраняются при
переходе между изображениями.

### Открытие датасета

Без `data` инструмент запускается на главной странице проекта, а датасет
выбирается или создаётся из браузера. Если передать `data=path/to/data.yaml`,
этот датасет откроется сразу, а стартовая строка сообщит количество изображений,
количество классов и доступен ли датасет для записи. Датасет только для чтения
тоже открывается и объясняет, почему в него нельзя писать.

### Совместный доступ и что делает `host`

`share=true` привязывается к wildcard-адресу, и другие машины в вашей сети
получают доступ к инструменту, а административные действия — переключение и
удаление проектов, запуск вычислений — остаются на этой машине.

Указание конкретного интерфейса в `host` делает нечто другое и менее
безопасное: сама машина становится неотличима от сетевого клиента, поэтому
административные права получает каждый клиент. При этом команда печатает
предупреждение в stderr. Лучше использовать `share=true`.

### Порты и завершение работы

Если порт занят, берётся следующий — и так до двадцати портов после
запрошенного. Если все двадцать заняты, команда завершается с `io_error`.
В stdout печатается URL с портом, к которому фактически удалось привязаться.
С `share=true` результат содержит ещё и `lan_url` — адрес, который должны
открыть коллеги.

Команда работает на переднем плане до Ctrl+C.

Смотрите также: [`libreyolo doctor`](/docs/cli/doctor) — проверить размеченный
датасет перед обучением, и [`libreyolo train`](/docs/cli/train) — обучить на нём.
